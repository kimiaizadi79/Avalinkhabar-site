مهم:
- خود فایل ZIP را داخل GitHub نگذارید.
- ZIP را Extract کنید.
- تمام فایل‌ها و پوشه‌های Extract شده را در ریشه Repository قرار دهید.
- index.html باید مستقیماً در ریشه Repository باشد، نه داخل یک پوشه دیگر.

GitHub Pages:
